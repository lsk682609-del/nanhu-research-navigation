## 1. 目标

能说出每个格子的代价从哪来，分清 254（真障碍）、253（内切带）、1–252（膨胀梯度）、0（自由），并解释为什么穿门不能依赖代价地图。

## 2. 关键参数与计算题

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `width/height` | 10 / 10 m | 滚动窗口 |
| `resolution` | 0.05 m | 一格 5 cm |
| `footprint` | 前 0.275 / 后 0.23 / 半宽 0.23 | 内切半径 **0.23 m** |
| `inflation_radius` | 0.45 m | 梯度最远延伸到多远 |
| `cost_scaling_factor` | 5.0 | 梯度衰减陡峭度 |
| `lethal_cost` | 253 | 控制器判“不可通行”的阈值 |

计算题：

1. 窗口格数 = `10 / 0.05` = **200 × 200**。
2. 门洞中线到门柱内缘 = 净宽 0.70 的一半 = **0.35 m**（> 内切 0.23，所以中线不是 253）。
3. 代价公式：

```text
d <= 0.23（内切）      → 253
障碍体内               → 254
d >= 0.45（膨胀半径）  → 0
中间                   → 253 * exp(-5.0 * (d - 0.23))
```

代入 d=0.35：`253 * exp(-5 * 0.12) ≈ 139`。

## 4. 穿门为何不能靠代价地图（几何推导）

1. 253 带从柱面往中线各延伸 0.23（考虑 0.05 栅格，实测约 0.25–0.26）；
2. 门净宽 0.70 → 中间自由带约 **0.19–0.24 m**；
3. 车体 footprint 宽 **0.46 m**（半宽 0.23）。

`footprintCostAt` 取 footprint 覆盖格的最大值 → 必然取到 253 → 控制器判内切碰撞，拒绝前进。

所以项目做了两件事：把 `lethal_cost` 设为 253（只拒绝内切/致命格，避免把膨胀梯度也当墙），以及门区改用 **点云测门柱距离** 绕开代价地图。

## 5. 关键结论

1. 253 是**内切带**（几何量，由内切半径 0.23 决定），254 是**真障碍**；`inflation_radius` 只决定梯度延伸多远，不改变 253 带宽度。
2. `lethal_cost` 越小越保守：253 → 200 会把距障碍 0.277 m 内的格子全判死，0.7 m 门直接被封。
3. 门心 cost 约 139，说明“梯度区”不等于“不可通行”；能否通过由 footprint 与阈值共同决定，而不是单点读数。
4. 窄门可通行性不能用代价地图判定，必须用点云测距 + 门区专用控制。
5. `cost_scaling_factor` 从 5 降到 2，衰减变慢 → 同一距离的 cost 升高（门心 139 → ≈199）。

## 7. 自测作答（参考答案）

1. **253 与 254 各代表什么？** 253 = `INSCRIBED_INFLATED_OBSTACLE`（内切带，几何上放不下车体中心）；254 = `LETHAL_OBSTACLE`（真实障碍格）；1–252 为按距离衰减的代价；0 为自由。
2. **内切半径如何从 footprint 得出？** footprint 是矩形，内切半径 = min(半宽 0.23, 半长)。本项目半宽 0.23 更小，故内切半径 = **0.23 m**。
3. **膨胀过大为什么封门？** 单靠 `inflation_radius` 不会封门；真正封门的是把 `lethal_cost` 降低（如 200），使更宽的梯度区被判死，自由带窄于车宽。

## 8. 复习要点

1. 254 障碍 / 253 内切 / 梯度 / 0 自由；阈值 253 是“只信内切与致命”。
2. 253 带宽度 = 内切半径（0.23），与 `inflation_radius` 无关。
3. 窄门靠点云，不靠 costmap。
