# 导航系统日志记录说明

## 日志文件

| 文件 | 说明 |
|------|------|
| `logs/navigation.log` | 文本事件日志 |
| `logs/recorder.csv` | 结构化数据日志 |

---

## recorder.csv 格式

### net,goal（目标点设置）

`net_navigator` 发布，每次收到新目标时记录。

```
ros_time,net,goal,exec_status,
gx,gy,gz,gr,gpi,gyaw
```

| 字段 | 含义 | 坐标系 |
|------|------|------|
| `ros_time` | ROS 时间戳（秒） | — |
| `exec_status` | 导航状态机状态 | — |
| `gx, gy, gz` | 目标点位置 | map |
| `gr, gpi, gyaw` | 目标点姿态 (roll/pitch/yaw) | map |

### net,exec（导航执行状态）

`net_navigator` 发布，每个控制周期一条。

```
ros_time,net,exec,exec_status,
rx,ry,rz,rr,rpi,ryaw,
distance_remaining,
tx,ty,tz,tr,tpi,tyaw
```

| 字段 | 含义 | 坐标系 |
|------|------|------|
| `rx, ry, rz` | 机器人当前位置 | map |
| `rr, rpi, ryaw` | 机器人当前姿态 (roll/pitch/yaw) | map |
| `distance_remaining` | 到目标剩余距离 (m) | — |
| `tx, ty, tz` | 当前追踪的子目标点 | map |
| `tr, tpi, tyaw` | 子目标点姿态 | map |

### ctrl,cvc（控制器速度指令）

`controller_server` 发布，每个控制周期一条。

```
ros_time,ctrl,cvc,exec_status,
rx,ry,rz,rr,rpi,ryaw,
cx,cy,cz,
curr_lin_x,curr_ang_z,
cmd_lin_x,cmd_ang_z,
cvc_method
```

| 字段 | 含义 | 坐标系 |
|------|------|------|
| `rx, ry, rz` | 机器人当前位置 | map |
| `rr, rpi, ryaw` | 机器人当前姿态 (roll/pitch/yaw) | map |
| `cx, cy, cz` | 预瞄点（carrot）位置 | **base_link** |
| `curr_lin_x` | 当前线速度 (m/s) | — |
| `curr_ang_z` | 当前角速度 (rad/s) | — |
| `cmd_lin_x` | 指令线速度 (m/s) | — |
| `cmd_ang_z` | 指令角速度 (rad/s) | — |
| `cvc_method` | 控制方法 | — |

### cvc_method 取值

| 值 | 含义 | 说明 |
|------|------|------|
| `APC` | Apply Constraints | 正常路径跟踪，线速度 × 曲率 = 角速度 |
| `RTG` | Rotate To Goal | 原地旋转对准目标朝向 |
| `RTP` | Rotate To Path | 原地旋转对准路径方向 |

### gp_goal / gp_path（GPS 原始目标）

`input_bridge` 发布。

```
ros_time,gp_goal,lat,lon,alt          ← GPS 目标点
ros_time,gp_path,lat,lon,alt          ← GPS 路径最后一点
```

---

## navigation.log 格式

格式：`[时间戳] [nav2] [级别] [节点名] 消息内容`

### 事件类型

| 来源 | 事件 |
|------|------|
| `input_bridge` | gp_origin 设置/验证、GPS 目标接收、GPS 路径接收 |
| `net_navigator` | 状态切换（IDLE→PLANNING→EXECUTING）、目标到达/取消/接收、规划超时/失败、路径切片重规划 |
| `net_planner` | 规划耗时 |
| `controller_server` | 角度/角速度超限警告、Theta\* 规划失败、碰撞检测报警 |

## 示例

### 正常路径跟踪

```
ctrl,cvc,0, 5.870,-0.234,-0.100,0.005,-0.025,1.862, 0.593,1.157,0.000, 0.500,0.000, 0.500,0.024, APC
              ← 机器人位姿 →              ← carrot → ← 当前 →  ← 指令 →
```

- 机器人在 map 系 (5.87, -0.23)，朝向约 1.86 rad
- 预瞄点在 base_link 系 (0.59, 1.16)，偏右侧
- 当前速度 0.5 m/s，角速度 0
- 指令速度 0.5 m/s，角速度 0.024 rad/s（轻微右转跟随 carrot）

### 原地转向

```
ctrl,cvc,0, 5.882,-0.244,-0.098,0.005,-0.024,1.927, 0.676,1.110,0.000, 0.000,0.000, 0.000,0.640, RTP
```

- 指令线速度 0，角速度 0.64 rad/s（原地旋转对准路径）
- `RTP` = Rotate To Path
